**GDAI MCP** is a **dev-only** Godot 4 plugin that lets Cursor (and other MCP clients) control the **Godot Editor** — create scenes, move nodes, read script errors, etc.

> **Full MCP stack:** This project also supports **Godotiq** (analyze/debug) and **Godot MCP Pro** (automated testing). See **`docs/ops/agents/MCP_STACK.md`** for roles, install, and conflict rules.
